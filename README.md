# Zimple — Local AI Agent

**Локальный ИИ-агент, который умеет управлять твоим компьютером.**
Без облака, без API-ключей, без подписок. Модель работает через
[LM Studio](https://lmstudio.ai/), сервер — Flask, браузер — Playwright,
рабочий стол — pyautogui + UIAutomation.

> Local AI agent that controls your browser, desktop and files
> via LM Studio. No cloud, no API keys.

---

## Что умеет

- 🌐 **Управляет браузером** — открывает сайты, кликает по элементам,
  печатает текст, скроллит. Через настоящий Chromium (Playwright).
- 🖥️ **Управляет рабочим столом Windows** — запускает программы,
  нажимает кнопки в любых окнах, печатает текст, работает с горячими
  клавишами. Через UIAutomation + pyautogui.
- 📁 **Работает с проектами** — читает, создаёт, правит файлы в
  выделенной папке. С patch-режимом точечных правок.
- 👁️ **Видит экран** — на каждом шаге делает скриншот и получает
  список интерактивных элементов активного окна.
- 💬 **Многошаговый агент** — сам планирует, делает шаг, смотрит
  результат, корректируется, идёт дальше.

---

## Что НЕ умеет (пока)

- Vision-модели для анализа пикселей (работаем через accessibility
  API и DOM, а не через «посмотри на картинку и кликни»)
- macOS и Linux для desktop-режима (только Windows)
- Игры и canvas-приложения (там нет accessibility-дерева)

## Быстрый старт

### Требования

- **Python 3.10+**
- **Windows 10/11** (для desktop-режима)
- **[LM Studio](https://lmstudio.ai/)** с загруженной моделью
- **~16 ГБ RAM/VRAM** для комфортной работы 12B-модели

### Шаг 1. Клонируй

```bash
git clone https://github.com/<твой-ник>/zimple-local-agent.git
cd zimple-local-agent
```

### Шаг 2. Установи зависимости

```bash
pip install -r requirements.txt
playwright install chromium
```

### Шаг 3. Запусти LM Studio

1. Открой LM Studio
2. Скачай модель — рекомендую **Qwen2.5-Coder-32B-Instruct** или
   **Gemma 3 12B** для слабых машин
3. Открой вкладку **Local Server** → **Start Server**
4. Сервер поднимется на `http://localhost:1234`

### Шаг 4. Настрой модель (опционально)

Скопируй точное имя модели из LM Studio и передай его через
переменную окружения:

```bash
# Windows (cmd)
set ZIMPLE_MODEL=qwen2.5-coder-32b-instruct
python app.py

# Windows (PowerShell)
$env:ZIMPLE_MODEL="qwen2.5-coder-32b-instruct"
python app.py

# Linux/macOS
ZIMPLE_MODEL=qwen2.5-coder-32b-instruct python app.py
```

Если не задавать — используется `google/gemma-3-12b` по умолчанию.

### Шаг 5. Запусти Zimple

```bash
python app.py
```

Откроется окно `pywebview`, либо приложение поднимется в браузере
на `http://127.0.0.1:5000`.

## Как пользоваться

### Обычный чат

Просто пишешь сообщение — модель отвечает. Работает как обычный
локальный чат.

### Агентный режим для браузера

В меню чата (**⋯** в правом верхнем углу) выбери **Режим → ИИ
(LM Studio)**. Теперь на каждое сообщение модель будет строить план
и выполнять его: открыть сайт, найти информацию, вернуть ответ.

### Управление рабочим столом

1. В меню чата включи **Управление ПК** — появится зелёная плашка
2. Напиши: *«на рабочем столе открой Блокнот и напиши привет»*
3. Агент начнёт выполнять шаги, сворачивая окно Zimple на время
   работы, чтобы не мешать сам себе

**Осторожно:** агент получает полный контроль над мышью и
клавиатурой. Резко дёрнуть мышь в левый верхний угол экрана —
аварийный стоп (pyautogui failsafe).

### Проекты

Нажми **Проекты** в сайдбаре → создай проект → загрузи файлы
(или перетащи папку прямо в окно). Дальше можно писать:
*«добавь валидацию в main.py»*, *«перепиши стили на тёмную тему»* —
агент будет читать файлы, точечно править, показывать результат.

---

Каждый агент работает в **отдельном worker-потоке** с очередью
команд — потому что и Playwright, и UIAutomation требуют, чтобы
все вызовы шли из одного потока. Flask обрабатывает запросы в
разных потоках, поэтому команды кладутся в очередь.

### Формат блоков

Модель отвечает всегда **одним JSON-объектом**:

```json
{
  "blocks": [
    {"type": "reasoning", "text": "Сначала открою Google"},
    {"type": "browser", "action": "goto", "url": "https://google.com",
     "text": "Открываю Google", "delay": 0.5}
  ],
  "content": "Открыл Google. Что искать?",
  "done": false
}
```

## Модели: что реально работает

| Модель | Размер | Агентные шаги | Комментарий |
|---|---|---|---|
| **Qwen2.5-Coder-32B** | ~19 ГБ | ⭐⭐⭐⭐⭐ | Лучший вариант для агента |
| **Qwen2.5-Coder-14B** | ~9 ГБ | ⭐⭐⭐⭐ | Хорошо, если мало VRAM |
| **Gemma 3 12B** | ~8 ГБ | ⭐⭐⭐ | Работает, но иногда «соскакивает» |
| **Gemma 4 12B** | ~8 ГБ | ⭐⭐⭐⭐ | Лучше следует инструкциям |
| **Gemma 4 26B-A4B (MoE)** | ~15 ГБ | ⭐⭐⭐⭐⭐ | Отличный баланс |
| **Llama 3.3 70B** | ~40 ГБ | ⭐⭐⭐⭐⭐ | Топ, но требует 48 ГБ VRAM |

**Правило:** чем больше модель — тем стабильнее агент следует
формату JSON и не «соскакивает» на разговоры вместо действий.

## Известные проблемы

- **Модель пишет «открыл сайт», но блока нет** — слабые модели
  (до 12B) часто описывают действие вместо того, чтобы его
  отправить. Переключись на модель покрупнее.
- **Клики улетают мимо** — если у тебя масштаб экрана 125% или
  150%, нужен DPI awareness. Он уже встроен, но если проблемы
  остались — открой `computer_agent.py` и проверь вызов
  `SetProcessDpiAwareness`.
- **Playwright не находит браузер** — выполни
  `playwright install chromium` после `pip install`.
